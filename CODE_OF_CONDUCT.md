# Code of Conduct

## Our Commitment

We want BioProspector to be a useful, accurate, and welcoming public skill
repo for everyone who shows up: scientists, engineers, agent operators,
students, and curious newcomers.

## Expected Behavior

- Be respectful in issues, pull requests, discussions, and review comments.
- Keep technical disagreements technical.
- Assume good faith and ask before reacting.
- Preserve claim discipline: prefer "candidate", "hypothesized",
  "domain-supported", or "characterized elsewhere" over unqualified
  production or validation claims.
- Credit prior work, sources, and accessions when bringing in examples.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Sustained disruption of project discussions.
- Publishing other people's private information without permission.
- Adding credentials, private paths, internal run logs, or unpublished
  biological data to the public repo or to issue or PR text.

## Reporting

Sensitive disclosure issues should go through the channel described in
[`SECURITY.md`](SECURITY.md). For conduct concerns, contact the repository
maintainers privately through the same channel.

## Scope

This Code of Conduct applies to project spaces, including the repository,
issues, pull requests, discussions, and any related public channels the
maintainers create or maintain.

## Attribution

This Code of Conduct is adapted from common open-source norms and the
Contributor Covenant. The repository maintainers are responsible for
clarifying and enforcing it.
