# Public roadmap

BioProspector already provides campaign scaffolds, ledger validation, evidence
ingest, issue drafts, review packages, and provider-readiness contracts. Future
work stays behind the same public-data and claim boundaries.

## Near-term work

- Add compact adapters for more sequence-family, structural-motif, reaction,
  BGC, and literature summaries.
- Strengthen schema validation for tool versions, database releases, evidence
  pointers, controls, and private-data status.
- Improve review surfaces built from ledgers and candidate graphs.
- Expand synthetic fixtures that exercise failure modes without introducing
  private or raw biological data.

## Later work

- Add portable execution-proof contracts for approved HPC, cloud, and managed
  workflow environments.
- Improve route-level Pareto views and degraded-path reporting.
- Add more metadata-only genome-context and source-prior workflows.

## Adoption gate

A roadmap item enters the supported workflow only when it has a bounded input
contract, compact output schema, license and data-policy review, failure mode,
tests, and a clear claim ceiling. See the dated
[`opportunity radar`](opportunity-radar.md) for external-tool candidates.
