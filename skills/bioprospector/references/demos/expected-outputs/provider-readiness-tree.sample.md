# Provider Readiness Tree Sample

Generated by `bioprospector_runpod_bundle.py` or
`bioprospector_elasticblast_bundle.py` under `.runtime/`.

```text
.runtime/runpod-readiness/nootkatone-yeast-v0/
├── README.md
├── readiness-contract.json
├── provider-launch-preflight.tsv
├── stage-contract-ledger.tsv
├── sequence-search-plan-ledger.tsv
├── expected-returned-ledgers.tsv
├── setup-preflight.sh
└── closeout-checklist.md
```

What the packet tells a user:

- which provider role the campaign needs
- what stage should run first
- what inputs are expected
- which outputs must come back as compact ledgers
- where resume and done markers live
- which budget, image, storage, data, and credential blockers stop launch
- how partial or failed runs should still return useful candidate intelligence

The readiness packet is useful even before execution because it turns a broad
search idea into a concrete, reviewable run contract.
