# Skills

This repo exposes one primary local skill:

- `bioprospector`: BioSymphony BioProspector campaign planning, issue contracts, candidate funnels, route stitching, and dossier validation.

Install it into a local agent environment with
[`../docs/AGENT_INSTALL.md`](../docs/AGENT_INSTALL.md). The skill stays
source-checkout oriented so scripts, schemas, examples, and docs remain in one
auditable place.
